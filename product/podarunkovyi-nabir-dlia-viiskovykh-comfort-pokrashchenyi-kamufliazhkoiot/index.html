Подарунковий набір для військових "Comfort Стандартний" (камуфляж+койот) — це збалансований комплект надійного спорядження, розроблений для виконання завдань у польових умовах, кемпінгу або виживання. Усі елементи  виготовлені зі зносостійких матеріалів.

Набір постачається у стильній крафтовій коробці з фірмовим логотипом бренду на внутрішній стороні кришки та декоративним дерев'яним наповнювачем.

Склад тактичного боксу:

  • Поясна тактична сумка-підсумок: Місткий та міцний органайзер із системою кріплень MOLLE, додатковими відділеннями на блискавках та надійною фастекс-застібкою для швидкого скидання.
  • Тактичні рукавиці без пальців (мітенки): Зі спеціальними захисними вставками-«кісточками» для захисту рук від механічних пошкоджень та вентиляційними отворами для комфорту.
  • Складаний ніж: Компактний інструмент із чорним покриттям леза, ергономічною ручкою, кліпсою для носіння на кишені та вбудованим склобоєм/стропорізом.
  • Карабін: із страхувальний шнуром.
  • Браслет із паракорду: Багатофункціональний аксесуар «виживання», що розплітається у міцну мотузку та має вбудований у застібку компас, свисток для подачі сигналів і міні-ніж.
